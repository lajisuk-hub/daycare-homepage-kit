# 🏡 우리 어린이집 홈페이지 만들기 (견본 틀)

큰 사진과 어린이집 소개가 들어간 **한 장짜리 어린이집 홈페이지** 틀입니다.
내려받아서 **글자와 사진만 바꾸면** 우리 어린이집 홈페이지가 됩니다.
프로그램 설치 없이, 컴퓨터에서 파일을 두 번 누르면 바로 열립니다.

## 들어 있는 칸

| 순서 | 칸 | 내용 |
|---|---|---|
| 1 | 맨 위 큰 사진 | 화면 가득 사진 + 대표 문구 + 단추 2개 |
| 2 | 우리의 하루 | 사진 2장 + 짧은 글 + 한 줄 자랑 3개 |
| 3 | 어린이집 소개 | 원장 인사말 + 개원·평가 같은 자랑거리 |
| 4 | 교육 이야기 | 특색 프로그램 카드 (사진 또는 아이콘) |
| 5 | 하루 일과 | 등원부터 귀가까지 시간표 |
| 6 | 오늘의 풍경 | 활동 사진 (누르면 크게 보기) |
| 7 | 입학 안내 | 보육 시간, 입소 절차, 전화 걸기 단추 |
| 8 | 오시는 길 | 주소로 지도 자동 표시 + 카카오맵·네이버지도 단추 |

휴대폰에서 열면 휴대폰 크기에 맞게 자동으로 바뀝니다.

---

## 1. 내려받기

1. 이 페이지 위쪽의 초록색 **`<> Code`** 단추를 누릅니다.
2. 맨 아래 **`Download ZIP`** 을 누릅니다.
3. 받은 zip 파일을 마우스 오른쪽 단추로 누르고 **「압축 풀기」** 를 누릅니다.
4. 풀린 폴더 안의 **`index.html`** 을 두 번 누르면 견본 홈페이지가 열립니다.

## 2. 우리 어린이집으로 바꾸기

### 방법 A — 클로드(Claude)에게 부탁하기 (추천)
폴더를 클로드 앱(Code 탭)에서 열고 이렇게 말하면 됩니다.

> 이 홈페이지를 우리 어린이집으로 바꿔줘. 이름은 ○○어린이집, 전화는 ○○○, 주소는 ○○○.
> 원장 인사말은 이렇게 넣어줘: ...
> images 폴더에 내 사진 넣었으니 맨 위 사진은 ○○.jpg로 바꿔줘.

폴더 안의 `CLAUDE.md` 에 클로드가 지켜야 할 방법이 적혀 있어서, 클로드가 알아서 알맞은 곳을 고칩니다.
"색을 분홍색으로 바꿔줘", "갤러리 사진 6장으로 늘려줘", "급식 안내 칸 추가해줘" 같은 부탁도 됩니다.

### 방법 B — 직접 고치기
고칠 파일은 딱 두 개입니다. (메모장으로 열어 고치고 저장)

| 바꾸고 싶은 것 | 고칠 파일 |
|---|---|
| 글자 (이름·인사말·시간표·전화·주소 등) | **`content.js`** |
| 사진 | **`images`** 폴더에 내 사진을 넣고 `content.js` 의 파일 이름을 바꾸기 |
| 색깔 | **`style.css`** 맨 위 9줄 |

- `content.js` 에서는 **따옴표(" ") 안의 글자만** 고치세요. 따옴표·쉼표·괄호를 지우면 홈페이지가 하얗게 나옵니다.
- 필요 없는 칸은 `show: true` 를 `show: false` 로 바꾸면 숨겨집니다.
- 줄바꿈은 글자 사이에 `\n` 을 넣습니다.
- 고친 뒤에는 `index.html` 을 다시 열어(또는 새로고침) 확인합니다.

### 📷 사진 고르는 요령
- 맨 위 큰 사진은 **가로로 긴 사진**, 가로 1600픽셀 이상이 선명합니다.
- 글자가 왼쪽에 올라가므로 **아이들이 오른쪽에 있는 사진**이 잘 어울립니다.
- 사진 파일 이름은 **영어·숫자**로 지어 주세요 (예: `spring1.jpg`). 한글 이름은 인터넷에 올리면 안 보일 수 있습니다.
- ⚠️ 아이 얼굴이 나온 사진은 **보호자 동의를 받은 사진만** 쓰세요.

## 3. 인터넷에 올리기 (주소 만들기)

홈페이지를 다른 사람도 볼 수 있게 하려면 인터넷에 올려야 합니다. 무료 방법 중 하나를 고르세요.

- **Netlify Drop (가장 쉬움)**: https://app.netlify.com/drop 에 접속 → 폴더를 통째로 끌어다 놓기 → 주소가 바로 생깁니다. (계정을 만들어야 주소가 계속 유지됩니다)
- **GitHub Pages**: 내 GitHub 계정에 이 폴더를 올리고 Settings → Pages 에서 켜기
- **Vercel**: GitHub에 올린 뒤 vercel.com 에서 Import

클로드에게 "이 홈페이지 인터넷에 올리는 거 도와줘"라고 하면 한 단계씩 안내해 줍니다.

## 폴더 안 파일

```
index.html   홈페이지 뼈대 (고치지 않아도 됨)
content.js   ✏️ 글자·사진 — 여기를 고치세요
style.css    🎨 색깔 (맨 위만 고치면 됨)
app.js       화면을 그려 주는 파일 (고치지 않아도 됨)
images/      📷 사진 폴더
CLAUDE.md    클로드에게 주는 작업 안내
```

견본 사진은 저작권 걱정 없는 무료 사진(StockSnap, CC0)입니다. 실제 사용할 때는 우리 어린이집 사진으로 바꿔 주세요.
